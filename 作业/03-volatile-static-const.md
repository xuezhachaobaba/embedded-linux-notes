## 1. `[考：知识点1、3]` 概念（这题跑不出效果，靠想）

```c
int flag = 0;          // 在中断里会被设成 1
while (flag == 0) { }  // 等 flag 变 1
```

开了优化（`-O2`）时，这段代码可能出什么问题？**怎么修？**

**答**：这里中断把flag设成1之后，主代码也不会读到，while也不会停，成了死循环。怎么修：定义的时候，前面加上volatile int flag = 0;这样中断里flag被设成1的话，会从内存里读取到，停止循环；
重新看课件重新回答：开了-O2优化后，编译器认为flag = 0，flag在while内，不会修改，就会把值缓存到寄存器，这时中断后及时变量修改了也读不到，要在flag初始化时候，阻止优化。

## 2. `[考：知识点4]` 判断对错

"`volatile` 让变量的读写在单条指令内完成，不会被中断打断（即原子操作）。"

**对还是错？为什么？**

**答**：错，因为在c里，volatile只保证变量从内存中读写，并不保证其他，可能会被中断打断，不保证原子操作。

## 3. `[考：知识点4]` 判断对错

"`volatile` 能保证多线程下的正确同步，用了 volatile 就不用加锁。"

**对还是错？为什么？**

**答**：错，因为在c里，volatile只保证变量从内存中读写，并不保证其他，多线程下的正确同步需要靠互斥锁和同步锁来解决。

**答**：static 局部变量存在静态存储区，初始化一次

## 8. `[考：知识点7]` 概念

在 `a.c` 里写 `static int secret;` 和（不写 static 的）`int secret;` 有什么**区别**？

**答**：分情况，如果是局部变量secret，写static让它成为静态局部变量，存放在静态存储区，函数返回后也不会被销毁，变量只初始化一次。如果是全局变量，static让它成为仅限a.c文件使用的全局变量，外部文件也不能通过extern来获取secret变量，可以限制作用域，防止命名冲突等。

## 11. `[考：综合]` 用一句话分别解释

各用一句话说清 `volatile` / `static` / `const` 的作用（像面试那样口头表达）。

- volatile：修饰的变量会从内存里读取数据，而不是寄存器之类的
- static：修饰的变量会存放在静态存储区，只初始化一次，全局变量的话会保证其它文件不可见
- const：修饰的变量为只读，不允许修改其值
