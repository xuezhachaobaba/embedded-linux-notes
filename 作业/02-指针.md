## 1. 下面代码输出什么？

```c
int a = 10;
int *p = &a;
*p = 20;
printf("%d\n", a);
```

**输出**：20

**为什么**：初始化a赋值为10，后初始化指针p的值为a的地址，然后解地址p，赋值为20，所以a的值为20

## 2. 下面代码输出什么？

```c
int a = 5;
int *p = &a;
printf("%d %d\n", a, *p);
```

**输出**：5 5
**为什么**: 因为a初始化为5，指针p的值为a的地址，然后a和解地址p的值都是5

## 3. 这段代码有什么问题？怎么改？

```c
int *p;
*p = 10;
```

**问题**：这里定义了一个指针，然后指针并没有收到一个变量的地址，而是直接解地址，赋值，指针需要先获取一个地址，然后才能解地址

**正确写法**：
int *p;
int a = 5;
p = &a;
*p = 10;

## 5.（理解）为什么下面代码里，main 中 `x` 的值不会变成 6？

```c
void add_one(int n) {
    n = n + 1;
}

int main(void) {
    int x = 5;
    add_one(x);
    // x 还是 5，不是 6
    return 0;
}
```

**答**：5，x的值不会变成6。因为函数是值传递，它只是在在函数里修改了内容，没有传递回下面。
