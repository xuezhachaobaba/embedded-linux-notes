## 9. `[考：知识点5]` 概念（面试原题）

默认拷贝构造是浅拷贝。①什么情况下浅拷贝会出事？②出事的具体机制（讲到 double free）？③深拷贝怎么写？

**答**：
三种情况下浅拷贝会出事
1.class a = b;
2.func(class a);
3.return a;
因为浅拷贝是会让ab公用同一个地址，这样等析构的时候，其中一个提前析构完，地址就没了会出现double free的状态

深拷贝，首先Buf(){},然后参数是Buf & other,最后函数体需要先new Buf，再this.data = other.data
深拷贝，先需要new一片和拷贝的对象一样大小的空间，将基础数据赋值之后，再将源堆里的数据赋值。

## 11. `[考：知识点7]` 初始化列表

`class Timer { const int id; int &counter; }`（引用成员！）。在构造函数 `Timer(int i, int &c)` 里**用初始化列表**完成两个成员的初始化，main 里验证能用。然后试试图里写 `id = i;` 会发生什么——贴报错，说明为什么 const 成员/引用成员只能走列表：

**答**：
（批改后补录）08.cpp 报错：
`error: uninitialized const member in 'const int'`（id should be initialized）
`error: uninitialized reference member in 'int&'`（counter should be initialized）
`error: assignment of read-only member 'Timer::id'`（id = i 那行）
原因：**构造函数体开始执行时，成员已经出生了**——const 成员出生后不能再赋值；引用成员必须出生时就绑好对象、之后永远不能换绑。初始化列表是"出生时给初值"，赶在赋值之前，所以是唯一途径。
