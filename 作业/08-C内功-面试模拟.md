### 5. `[考：06]` 栈 vs 堆

「栈和堆有什么区别？都有了栈，为什么还需要堆？」

**答**：
栈是由程序自动调度的，而堆则是程序员调度的，栈是从高往低使用，而堆是从低往高使用
栈是函数调用等，会给每个新函数开辟一个空间，比较小，但是快，函数调用结束，就弹栈销毁，堆是用户自己申请一片内存空间使用，空间大，但是慢，需要用户手动释放。

### 9. `[考：06]` 这段代码错几处？

```c
char *msg(void) {
    char buf[32] = "hello";
    return buf;
}

void demo(void) {
    int *p = malloc(100 * sizeof(int));
    for (int i = 0; i <= 100; i++)
        p[i] = i;
    printf("%d\n", p[0]);
    free(p);
    free(p);
}
```

（提示：至少 4 处。假设头文件都齐。）

**答**：
首先*msg函数，是调用的，所以是在栈里，而栈只有40字节大小，buf数组的大小明显超出了40字节，所以buf[32]结果肯定不可行；其次，在return结束之后，buf就是野指针，我们return的到的buf结果就可能出错了.
在demo函数里，malloc申请了100个int类型大小的空间，但是for循环里使用了101个空间，会造成溢出，然后在释放的时候，释放了两遍p指针，会造成double释放报错
修改方法：
char msg(char *buf,int long){
    *buf = "hello";
    return buf;
}
void demo(void) {
    int *p = malloc(100 * sizeof(int));
    for (int i = 0; i < 100; i++)
        p[i] = i;
    printf("%d\n", p[0]);
    free(p);
}
