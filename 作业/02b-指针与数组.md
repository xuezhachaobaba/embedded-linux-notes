## 10. `[考：知识点7]` 逐行判断是否合法（编译验证：不合法的会报错）

```c
int a = 1, b = 2;
const int *p1 = &a;
int * const p2 = &a;

*p1 = 10;    // 合法？
p1 = &b;     // 合法？
*p2 = 10;    // 合法？
p2 = &b;     // 合法？
```

逐行判断（合法/不合法）+ 为什么：
*p1 = 10;不合法，const int * p1,这里是数据只读，只能修改指针，不能修改数据。
p1 = &b;合法，可以修改指针。
*p2 = 10;合法，int * const p2,这里是指针只读，不能修改指针，可以修改数据。
p2 = &b;不合法，不可以修改指针。
编译验证预测结果对：
error: assignment of read-only location ‘*p1’ *p1 = 10;
error: assignment of read-only variable ‘p2’ p2 = &b;

## 12. `[考：综合·理解]` 不用跑

为什么 C 函数接收数组时，通常还要**再传一个长度参数** `void foo(int a[], int n)`？

**答**：因为我们在定义数组a[]的时候，a代表的是数组的首地址，这时候想知道数组的长度的话，可以直接通过sizeof来获取。但是当a传递到函数当形参的时候，a在函数里就退化成指针了，这时候只能获取到数组的地址，不能通过sizeof来获取数组的长度，所以需要再穿一个长度参数，不然函数内操作容易超出数组范围。
