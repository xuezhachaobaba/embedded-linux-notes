## 4. `[考：知识点2]` 爆栈实验

```c
int main(void) {
    int a[10 * 1024 * 1024];   // 40MB 的栈上数组
    a[0] = 1;
    return 0;
}
```

**预测**：能跑吗？跑一下验证（跑完 `echo $?` 看退出码，139=段错误）。再把数组改成 `static int`（去别处了），再跑一次。两次结果+原因：
第一次应该不能跑，开始的int a数组是在栈区，每个栈帧只有8MB，放不下40MB的数组，所以栈溢出爆炸，把数组改成static int可以跑，这里把数组放到.data区去了，这里没有大小限制

## 5. `[考：知识点3]` 经典找错

```c
int* get_num(void) {
    int x = 42;
    return &x;
}
int main(void) {
    int *p = get_num();
    printf("%d\n", *p);
}
```

错在哪？**为什么可能打印出 42 却仍是错的**？写出三种修法：

**答**：在get_num函数里，return之后，这个函数所在的栈帧就会被弹掉，虽然可能没有销毁，但是这块地址会变成没有使用的地址，这时候任何代码都可能占用这块地址，所以我们返回的指针就会变成一个野指针，不过有可能这块指针的内容没有被修改，所以有可能会输出42
写法1
int get_num(void){
    int x = 42;
    return x;
}
写法2
void get_num(*x){
    *x = 42;
}
写法3,忘了，等下重新看一下
int * get_num(void){
    static int x = 42;
    return &x;
}

## 7. `[考：知识点4]` malloc 全流程（先预测再跑）

```c
#include <stdio.h>
#include <stdlib.h>
int main(void) {
    int *p = malloc(5 * sizeof(int));
    printf("申请后未初始化，内容：\n");
    for (int i = 0; i < 5; i++) printf("%d ", p[i]);
    printf("\n");
    for (int i = 0; i < 5; i++) p[i] = (i+1) * 10;
    for (int i = 0; i < 5; i++) printf("%d ", p[i]);
    printf("\n");
    free(p);
    return 0;
}
```

**预测**：第一行打出什么（确定值还是垃圾）？第二行呢？
第一行打印的是垃圾，这时候只是申请了地址，但是地址内的内容并没有初始化，所以还是之前保留的内容
第二行打印的是 10 20 30 40 50

## 11. `[考：知识点7]` 笔试经典

```c
char *a = "hello";
char  b[] = "hello";
a[0] = 'H';
b[0] = 'H';
```

哪行出问题？出什么问题？为什么 `b` 就没事？（可跑验证，注意用 sanitizer 更清楚）

**答**：因为a保存的是地址，a是指针变量，"hello"是常量，存放在常量区，常量区是只读的，不能去通过指针修改常量区的值
b保存的是数组，b有自己的一片地址空间，"hello"仍然是常量，但是在初始化的时候，常量复制到了b自己的内存空间，所以b可以修改自己内存空间的值
