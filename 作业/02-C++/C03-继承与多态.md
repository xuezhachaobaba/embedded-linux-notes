## 3. `[考：知识点3]` 虚 vs 非虚（先预测再跑）

```cpp
class A {
public:
    void     f() { std::printf("A::f\n"); }
    virtual void g() { std::printf("A::g\n"); }
};
class B : public A {
public:
    void f() { std::printf("B::f\n"); }
    void g() { std::printf("B::g\n"); }
};
int main() {
    A* p = new B;
    p->f();
    p->g();
    return 0;
}
```

**预测**（两行输出各是什么？为什么不一样）：
A::f
B::g
因为没有加virtual的话，最后会调用基类的，加了后面重写才用子类的方法
