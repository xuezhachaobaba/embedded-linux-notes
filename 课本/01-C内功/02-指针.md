# 02 指针（基础）：地址、`&` 与 `*`

> 指针是 C 里最重要、也最容易劝退的一章。别慌，我拆成几节，今天只打地基：搞懂"地址、`&`、`*`"。

## 学习目标

- 理解"指针 = 存地址的变量"
- 掌握 `&`（取地址）和 `*`（解引用）
- 理解指针类型的作用（读/写几个字节、`+1` 走多远）
- 能用指针修改另一个变量

## 内存模型（先建立直觉）

把内存想成**一长排格子**，每格 1 字节，每格有个编号，这个编号就叫**地址**。

```
地址:   0x1000  0x1001  0x1002  0x1003  ...
内容:  [         a 的 4 字节（值=10）       ] ...
```

当你写 `int a = 10;`，编译器在某几个**连续格子**里放下 10，并记下起始地址（比如 0x1000）。
- 变量名 `a` 是这几格内容的"**名字**"；
- 地址是这几格的"**门牌号**"。

## 什么是指针

指针 = 一种**专门用来存地址**的变量。

```c
int a = 10;
int *p = &a;   // p 是"指向 int 的指针"，里面存的是 a 的地址
```

比喻：`a` 是装着 10 的盒子，盒子上贴着门牌号；`p` 是个小本本，上面记着 `a` 的门牌号。

## 两个核心操作符

| 符号 | 名字 | 作用 |
|---|---|---|
| `&` | 取地址 | `&a` = "a 在哪"，得到 a 的地址 |
| `*` | 解引用 | `*p` = "按 p 里记的地址，去那个盒子里取东西" |

```c
int a = 10;
int *p = &a;

printf("%d\n", *p);   // 10 —— 顺着 p 找到 a 的值
*p = 20;              // 通过 p，把 a 改成 20！
printf("%d\n", a);    // 20
```

> 口诀：`&` 是"问地址"，`*` 是"按地址取东西"。它俩是一对反操作：`*(&a)` == `a`。

## ⚠️ 野指针（未初始化的指针）——必坑

```c
int *p;        // 只声明了指针，没给它地址
*p = 10;       // 💥 灾难！
```

- `int *p;` 只是分配了那个"小本本"，但**没在上面写字**——里面的地址是个**垃圾值**。
- `*p = 10` = "按这个垃圾地址找盒子塞 10"——可能改坏别的变量，也可能直接**段错误（segfault）崩溃**。这叫**未定义行为（Undefined Behavior, UB）**。

**铁律：指针在解引用（`*p`）之前，必须先指向一个合法地址。**

正确做法（二选一）：
```c
// ① 让它指向一个已有变量
int a;
int *p = &a;
*p = 10;

// ② 暂时不指任何东西，先用 NULL 占位
int *p = NULL;     // NULL = "空地址"，明确表示还没指
// 用之前再赋值：p = &a; 然后 *p = 10;
```

> `NULL` 是特殊值，表示"不指向任何东西"。**解引用 NULL 也会崩**，但它至少是个明确标记，方便检查：`if (p != NULL) { *p = 10; }`。野指针 / 空指针是面试常考点。

## 指针的类型有什么用？

`int *p` 里的 `int` 可不是装饰。它有两个作用：

1. **决定解引用读/写几个字节**：`int *` 操作 4 字节，`char *` 操作 1 字节。
2. **决定 `p + 1` 走多远**：`int *` 的 `p+1` 跳 4 字节，`char *` 的 `p+1` 跳 1 字节。

> 第 2 点是指针和数组紧密相关的关键，下节课（指针与数组）详讲。

## 指针自己占多少字节？

不管 `int*` 还是 `char*`，**指针变量本身**在 64 位系统上都占 **8 字节**（它存的是一个地址，地址是 64 位）。

⚠️ 别把"**指针的大小**"和"**它指向的类型的大小**"搞混：
- `sizeof(int*)` = 8（指针本身）
- `sizeof(int)` = 4（它指向的 int）

## 为什么需要指针？（预告）

C 函数传参是**值传递**——函数收到的是**副本**。想在函数里改外面的变量，就得把**地址**传进去：

```c
void add_one(int *p) {
    *p = *p + 1;     // 顺着地址，改外面的那个变量
}

int main(void) {
    int x = 5;
    add_one(&x);     // 传 x 的地址
    // 现在 x == 6
}
```

这叫"**传址调用**"，是指针最经典的用途。这就是为什么没有指针，C 就写不出很多功能。
