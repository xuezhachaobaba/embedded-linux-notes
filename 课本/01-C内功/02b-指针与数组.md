# 02b 指针与数组、指针算术、const 指针

> 上一节学了"指针 = 存地址的变量"。这节解决一个关键问题：**指针和数组到底是什么关系**，以及为什么 `p+1` 不是地址 +1。这些是面试高频，必须跑代码吃透。

## 学习目标

- 搞懂"数组名几乎就是指针"
- 掌握指针算术的步长规则
- 能用指针遍历数组、算元素个数
- 知道数组名和指针的**两个关键不同**
- 看懂 const 指针三种写法

## 1. 数组名 = 指向首元素的指针　`[知识点1]`

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;          // a 在这里"退化"成 &a[0]
// 等价写法：int *p = &a[0];
printf("%d\n", *p);  // 10（p 指向首元素）
```

数组名 `a` 在大多数表达式中，会自动**退化（decay）**成"指向第 0 个元素的指针"。所以能把数组名直接赋给指针。（例外见知识点 6。）

## 2. *(p+i) 等价于 a[i]　`[知识点2]`

```
a[i]   等价于   *(a + i)
&a[i]  等价于   (a + i)
```

也就是说，`a[i]` 本质是"从首地址 a 往后偏移 i 个元素，再解引用"。

```c
int a[3] = {10, 20, 30};
printf("%d %d\n", a[1], *(a+1));   // 20 20 —— 完全一样
```
> 冷知识（了解即可）：因为 `*(a+i)` == `*(i+a)`，所以 `a[i]` 和 `i[a]` 居然等价。别在工程里这么写。

## 3. 指针算术：p+1 跳一个"元素"，不是 1 字节　`[知识点3]` ⭐面试高频

```c
int a[5];
int *p = a;       // p 是 int*
// p+1 的地址增量 = 1 × sizeof(int) = 4 字节，而不是 1 字节！
```

**通用规则**：`p + n` 的地址增量 = `n × sizeof(*p)` 字节。**步长由指针指向的类型决定。**

```
int    *pi ;   pi + 1  跳 4 字节   (一个 int)
char   *pc ;   pc + 1  跳 1 字节   (一个 char)
double *pd ;   pd + 1  跳 8 字节   (一个 double)
```
> 坑：同样写 `p+1`，`char*` 跳 1、`int*` 跳 4。**类型决定步长**——这就是上节说"指针类型不是装饰"的真正含义。

## 4. 用指针遍历数组　`[知识点4]`

```c
int a[5] = {10, 20, 30, 40, 50};
for (int *p = a; p < a + 5; p++) {
    printf("%d ", *p);
}
// 输出：10 20 30 40 50
```
`p++` 让指针前进一个元素，`p < a+5` 防止越界。和用 `a[i]` 下标遍历等价，但更"底层"。

## 5. 指针相减 = 元素个数；指针比较　`[知识点5]`

```c
int a[5];
int *p1 = &a[1];
int *p2 = &a[4];
printf("%ld\n", p2 - p1);   // 3 —— 之间隔了 3 个元素（不是 12 字节）
```

- **两个指针相减**（指向同一数组）= 它们之间的**元素个数**，类型是 `ptrdiff_t`（用 `%ld` 或 `%td` 打印）。
- **指针比较**（`<`、`<=`、`==`…）：判断相对位置 / 是否越界，如 `p < a+5`。

> 坑：只有**指向同一数组**的两个指针相减才有意义。跨数组相减是未定义行为。

## 6. 数组名 ≠ 指针的两个关键不同　`[知识点6]` ⭐面试必考

数组名虽然能当指针用，但有两点不一样：

**① `sizeof(数组名)` 拿到的是整个数组的大小**
```c
int a[5];
int *p = a;
printf("%zu %zu\n", sizeof(a), sizeof(p));   // 20 8
// sizeof(a) = 5×4 = 20（整个数组）；这是数组名不退化的少数场景之一
// sizeof(p) = 8（指针本身）
```

**② 数组名不可修改（它是常量地址）**
```c
int a[5];
int *p = a;
a++;        // ❌ 编译错误！a 不能被赋值/自增
p++;        // ✅ 指针可以
```

**经典坑（面试爱考）**：数组传进函数后会退化成指针，函数里 `sizeof` 算不出数组长度——
```c
void print_size(int arr[]) {
    printf("%zu\n", sizeof(arr));   // 8！arr 已退化成指针
}
```
**这就是为什么 C 里传数组总要多带一个长度参数**：`void foo(int a[], int n)`。

## 7. const 指针三种　`[知识点7]` ⭐面试常考

const 加在不同位置，意义不同。记住一句口诀：

> **const 在 `*` 左边 → 指的东西只读；const 在 `*` 右边 → 指针本身只读。**

```c
int a = 1, b = 2;

const int *p1 = &a;     // const 在 * 左边：不能通过 *p1 改值
*p1 = 10;               // ❌ 不合法（指的东西只读）
p1 = &b;                // ✅ 可以（指针本身能改）

int * const p2 = &a;    // const 在 * 右边：指针本身只读
*p2 = 10;               // ✅ 可以（指的东西能改）
p2 = &b;                // ❌ 不合法（指针本身只读）

const int * const p3 = &a;  // 两边都 const：都只读
```
> `const int *p` 和 `int const *p` 是**一样**的（const 都在 `*` 左边）。工程里常见用 `const int *p` 当"只读数据"的参数，防止函数内部误改数据。
