# 01 位运算：嵌入式的看家本领

## 学习目标

- 掌握六个位运算符
- 牢记"置位 / 清零 / 翻转 / 读取"四大操作，能徒手写出来
- 理解每条操作"为什么这么写"

## 为什么重要

在嵌入式 Linux 里，你经常要改**寄存器**或**标志位**的某几个 bit，又**不能影响其它位**。这套套路叫 **read-modify-write**（读出 → 改某几位 → 写回），而位运算是实现它的唯一工具。C 面试也几乎必考。

> 场景举例：点亮一个 LED = 把某寄存器的第 5 位置 1；关掉 = 清 0；闪烁 = 翻转。

## 基础：六个运算符

设 `a = 0b1010`、`b = 0b1100`：

| 符号 | 名字 | 结果 | 规则 |
|---|---|---|---|
| `&` | 按位与 | `1000` | 都为 1 才为 1 |
| `\|` | 按位或 | `1110` | 有 1 即为 1 |
| `^` | 按位异或 | `0110` | 不同为 1 |
| `~` | 按位取反 | 单目 | 0/1 互换 |
| `<<` | 左移 | `a<<2 = 101000` | 低位补 0，相当于 ×2ⁿ |
| `>>` | 右移 | `a>>1 = 101` | 无符号数高位补 0 |

> 位编号约定：**bit0 是最低位**（最右边那一位）。`1 << 0` = 1，`1 << 7` = 128。

## 核心：四大操作（背下来）

设 `uint8_t reg;` 是一个 8 位寄存器。

### ① 置位（某一位变 1）
```c
reg |= (1U << n);
```
**为什么**：或运算 `1 | x = 1`（强制变 1）、`0 | x = x`（不变）。所以 `(1<<n)` 这个"只有 bit n 为 1"的掩码和 reg 或一下，只有 bit n 被置 1，其余不动。

### ② 清零（某一位变 0）
```c
reg &= ~(1U << n);
```
**为什么**：与运算 `0 & x = 0`（强制变 0）、`1 & x = x`（不变）。要清 bit n，需要"bit n 为 0、其余全 1"的掩码 → 就是 `~(1<<n)`。

### ③ 翻转（0 ↔ 1）
```c
reg ^= (1U << n);
```
**为什么**：异或 `1 ^ x = ~x`（翻转）、`0 ^ x = x`（不变）。

### ④ 读取某一位
```c
if (reg & (1U << n)) { /* bit n 是 1 */ }
```
**为什么**：`reg & (1<<n)` 结果非 0，就说明该位是 1。

## 实战例子

```c
#define LED_PIN  5

reg |=  (1U << LED_PIN);      // 置位 bit5：点亮
reg &= ~(1U << LED_PIN);      // 清零 bit5：熄灭
reg ^=  (1U << LED_PIN);      // 翻转：闪烁
if (reg & (1U << LED_PIN)) {} // 读取当前状态
```
用 `#define` 给位起名字，是工程里的好习惯——以后改引脚只改一处。

## 进阶贴士

1. **位编号**：bit0 = 最低位（最右）。别和"第几个"搞混。
2. **用 `1U << n`**：字面量 `1` 默认是 `int`（有符号），左移到符号位会出问题。写 `1U`（无符号）更安全。
3. **多位同时操作**：
   ```c
   reg |=  (1U<<0) | (1U<<3);     // 同时置位 bit0、bit3
   reg &= ~((1U<<1) | (1U<<4));   // 同时清零 bit1、bit4
   ```
4. **经典面试题**（了解原理）：不用临时变量交换两个数 `a ^= b; b ^= a; a ^= b;`

## 练习与自测

设 `uint8_t reg = 0x00;`（8 位全 0），**一步步累积操作**：

**1.** 把 **bit2** 置 1 —— 写代码 + 此时 reg 的二进制值
<details><summary>👀 答案</summary>

`reg |= (1U << 2);` → reg = `0b0000_0100`（= 0x04）
</details>

**2.** 接着把 **bit5** 也置 1 —— 此时 reg 的值
<details><summary>👀 答案</summary>

reg = `0b0010_0100`（= 0x24）
</details>

**3.** 再把 **bit2** 清 0 —— 此时 reg 的值
<details><summary>👀 答案</summary>

`reg &= ~(1U << 2);` → reg = `0b0010_0000`（= 0x20）
</details>

**4.** 怎么**一句话**把 bit0 和 bit3 同时置 1？
<details><summary>👀 答案</summary>

`reg |= (1U<<0) | (1U<<3);`
</details>

**5.（理解题，重点）** 清零为什么必须用 `reg &= ~(1<<n)`，**不能**直接写 `reg = ~(1<<n)`？
<details><summary>👀 答案</summary>

因为 `reg = ~(1<<n)` 是**直接赋值**，会把 reg 所有位都覆盖掉（除了 bit n 为 0，其余全被设成 1）。而 `&=` 是 read-modify-write，**只动 bit n，其余保持原样**——这正是操作寄存器必须做到的：你不能为了改一位把别的位全毁了。
</details>
