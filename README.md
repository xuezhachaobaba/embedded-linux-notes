# 嵌入式 Linux 开发学习笔记

> 方向：**嵌入式 Linux**（求职）。起点：会一点 C、不太懂硬件。
> 起步环境：**WSL2 (Ubuntu 26.04) + QEMU**，每天约 3 小时。
> 私教：Claude。每次课后重点沉淀到本仓库——忘了直接搜文件，不翻聊天记录。

## 怎么用这个仓库

| 路径 | 作用 |
|------|------|
| `00-路线图.md` | 整体路线 + 硬件清单 + 时间线 |
| `课本/` | 讲义（永久参考资料），每课一篇 |
| `作业/` | 每课作业文件，题目已摆好，你直接在里面写答案；写完招呼我批改 |
| `笔记/` | 重点、口诀、易错点——课后沉淀 |
| `错题本/` | 每道错题 + 正解 + 为什么错。面试前最高效的复习材料 |

**节奏**：讲课（写进 `课本/`）→ 做练习 → 批改 → 要点和错题沉淀进 `笔记/`、`错题本/`。
**阅读**：VS Code 里对着 `.md` 按 `Ctrl+Shift+V` 预览；全文搜索 `Ctrl+Shift+F`。
