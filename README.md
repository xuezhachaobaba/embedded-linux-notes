## 学习流程（我们的规矩）

1. **课更厚 + 知识点清单**：每节讲义带一栏编号「知识点」，每条配例子和"坑"。
2. **作业题标 `[考：知识点X]`**，能跑的题一律"**先预测 → 再编译运行验证**"——跑出来对得上就是会了，不用等我改。
3. **一口气做完一整节**，只把"卡住的 / 想确认的 / 没想通的"带给我。批改后先把错题和注意点跟你过一遍，**你确认没问题才算关课**；关课你再开下一课，我同时备后面的课。
4. **我专注高价值环节**：讲难点、调 bug、出不能跑代码的面试题、押八股、纠自查不出的误解。
5. **阶段性面试模拟**：每隔一段出一套纯概念/找错题，验证真懂 + 练面试。

6. **复习靠回头看**（2026-09-30 起总结停写）：错题进 `错题本/`、口诀进 `笔记/`；忘了翻课本，面试前用错题本 + 08 残卷自测。

> 原则：作业考的点，讲义一定先讲到。题考的点清单里没有 = 当场发现，漏不了。
**阅读**：VS Code 里对着 `.md` 按 `Ctrl+Shift+V` 预览；全文搜索 `Ctrl+Shift+F`。
