## 开发环境速记

- 编译运行：`gcc 源文件 -o 输出`，然后 `./输出`
- 默认带警告+调试编译：`gcc -Wall -g -std=c11 源文件 -o 输出`
- gcc 四阶段口诀：**预 → 编 → 汇 → 链**
  - 预处理（`-E`，`.i`）→ 编译（`-S`，`.s`）→ 汇编（`-c`，`.o`）→ 链接（可执行）
- ⚠️ 易错（踩过坑）：`-o` 是"给输出文件起名"，不是某个阶段；**汇编阶段用 `-c`**（产出 `.o`）。**运行 `./xx` 不属于编译阶段**。
- 我的环境：WSL2 Ubuntu 26.04，gcc 15.2，make 4.4，QEMU 未装（用到再装）

## 位运算速记（四大操作）

- 置位：`reg |=  (1U << n);`
- 清零：`reg &= ~(1U << n);`
- 翻转：`reg ^=  (1U << n);`
- 读取：`if (reg & (1U << n))`
- 多位同时：置位 `reg |= (1U<<a) | (1U<<b);`，清零 `reg &= ~((1U<<a)|(1U<<b));`
- 位编号：bit0 = 最右。`1U<<n` = 2ⁿ：
  - 1U<<0=0x01, <<1=0x02, <<2=0x04, <<3=0x08, <<4=0x10, <<5=0x20, <<6=0x40, <<7=0x80
- ⚠️ 易错（踩过坑）：清零用 `~`（按位取反），**别用 `!`（逻辑非）**。`!(1U<<2)`=`!4`=`0`，`reg &= 0` 会清光所有位。

## 指针速记（基础）

- `&` 取地址，`*` 解引用（按地址取/改东西），互为反操作：`*(&a)` == `a`
- 指针 = 存地址的变量；64 位系统上**指针本身 8 字节**，和指向的类型无关
- 指针类型决定：① 解引用读写几个字节 ② `p+1` 跳多远（下节课详讲）
- ⚠️ 野指针（未初始化）解引用是**未定义行为**，可能崩。解引用前必须让指针指向合法地址（或先 `= NULL`）

## 指针与数组速记（02b）

- 万能等式：**步长 = `sizeof(*p)`**；测步长用**地址差** `(char*)(p+1)-(char*)p`，别用 `sizeof(p+1)`（永远 8）
- 64 位改变的是**指针宽度**（8），**int 仍是 4**（LP64：char 1 / short 2 / int 4 / long 8 / 指针 8）
- `a[i]` ≡ `*(a+i)`；数组名 = 指向首元素的指针，但**能读不能改**（`a++` 报错：不是可修改左值；`a+1` 合法）
- 数组传参立即退化成指针：`void f(int a[])` ≡ `void f(int *a)`，函数内 `sizeof(a)` = 8 → **必须另传长度 n**
- `sizeof(a)`（数组）= 总字节数；元素个数 = `sizeof(a)/sizeof(a[0])`（仅对实参数组成立，传参后失效）
- 指针相减 = **元素个数**，不是字节数（`&a[4]-&a[1]` = 3）
- const 口诀：**`*` 左 const → 数据只读；`*` 右 const → 指针只读**（`const int *p1` vs `int * const p2`）
- `(char*)a` 强转：地址不动，换"眼镜"——按 char 看，步长变 1，可逐字节看内存（04 大小端要用）
